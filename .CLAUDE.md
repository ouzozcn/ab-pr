# A&B İletişim — Cursor Project Rules

## Project Overview

Bu proje, Türkiye'nin ilk halkla ilişkiler şirketi olan **A&B İletişim**'in kurumsal web sitesidir (1974'ten bu yana). TanStack Start üzerine inşa edilmektedir.

**Tech Stack:** TanStack Start · React · TypeScript · Tailwind CSS  
**Language:** Tüm kullanıcıya yönelik metin Türkçe olmalıdır.

- "Hızlı Keşfet" ikonları → Hizmetler / Projeler / İletişim

## Code Style Rules

- **TypeScript strict mode** — `any` kullanma, her şeyi type et
- **Tailwind only** — ayrı CSS dosyası yazma; brand renkleri her zaman token üzerinden (`bg-brand-primary`, `text-brand-dark`)
- **TanStack Router** — `createFileRoute` kullan, loader'ları route dosyasında tut
- **Named exports** — component dosyalarında hem named hem default export
- **Turkish content** — tüm kullanıcıya görünen string Türkçe; kod değişken isimleri İngilizce
- **Responsive first** — mobile-first Tailwind breakpoint'leri (`sm:`, `md:`, `lg:`)
- **Accessibility** — semantic HTML, `aria-label`, keyboard navigation
